# Issue #70 — Conteúdo e Microcopy do CallZUP

## 1. Objetivo

Definir textos claros, objetivos e consistentes para orientar os usuários durante a utilização do CallZUP.

A comunicação deve facilitar o entendimento das funcionalidades e reduzir dúvidas durante as operações logísticas.

## 2. Tom de voz

A linguagem do CallZUP deve ser:

- Clara: utilizar palavras de fácil compreensão.
- Objetiva: evitar mensagens longas e desnecessárias.
- Profissional: manter uma comunicação adequada ao ambiente corporativo.
- Orientativa: explicar o que aconteceu e o que o usuário pode fazer.
- Consistente: utilizar os mesmos termos para funcionalidades equivalentes.

| Arquivo muito grande | O arquivo excede o tamanho permitido. |
| Busca sem resultados | Nenhum resultado encontrado. Tente outra pesquisa. |

## 6. Mensagens de orientação

| Situação | Mensagem |
|---|---|
| Campo de mensagem vazio | Digite uma mensagem antes de enviar. |
| Busca vazia | Digite algo para pesquisar. |
| Conversa sem mensagens | Esta conversa ainda não possui mensagens. |
| Lista vazia | Nenhum registro disponível no momento. |
| Confirmação de saída | Deseja realmente sair da sua conta? |

## 7. Padronização de termos

Utilizar os seguintes termos de maneira consistente:

- Conversa: espaço de comunicação entre colaboradores.
- Mensagem: conteúdo enviado dentro de uma conversa.
- Equipe: grupo de colaboradores de uma área.
- Unidade: local ou setor operacional.
- Ocorrência: registro de um problema ou situação operacional.
- Solicitação: pedido de ação ou atendimento.

## 8. Recomendações de UX Writing

- Evitar mensagens técnicas que o usuário não compreenda.
- Informar claramente quando uma ação foi concluída.
- Explicar como corrigir um erro sempre que possível.
- Evitar mensagens genéricas como "Erro desconhecido" sem orientação adicional.
- Manter consistência entre botões, notificações e mensagens.
- Não expor informações sensíveis em mensagens de erro.
